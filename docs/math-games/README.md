# 🎮 ألعاب الرياضيات — منصة تفاعلية لرياضيات المرحلة الإعدادية (المنهج الليبي)

منصة ألعاب رياضيات متكاملة تعمل في المتصفح (هاتف وكمبيوتر) وبدون إنترنت بعد أول زيارة، موجّهة لطلاب
المرحلة الإعدادية في ليبيا: بنك أسئلة يغطي الصفوف الثلاثة، وستة أصناف من الألعاب، ونقاط وشارات
ومستويات ولوحة متصدرين وحفظ تلقائي للتقدّم.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادماً محلياً من داخل المجلد:

```bash
npx serve .          # أو: python -m http.server 8080
```

> النشر: المجلد داخل `docs/` في تعمل تلقائياً على GitHub Pages مع بقية الموقع
> على المسار `/math-games/`.

## الملفات

| الملف | الوظيفة |
|------|---------|
| `index.html` | الهيكل العام وحمّل السكربتات |
| `css/style.css` | التصميم كامل (فاتح/ليلي، متجاوب) |
| `js/helpers.js` | أدوات توليد الأسئلة + بُنااتها + التحقق منها |
| `js/data/g1.js` | بنك أسئلة **الأول الإعدادي** (6 وحدات) |
| `js/data/g2.js` | بنك أسئلة **الثاني الإعدادي** (6 وحدات) |
| `js/data/g3.js` | بنك أسئلة **الثالث الإعدادي** (6 وحدات) |
| `js/curriculum.js` | تجميع المنهج، تجهيز بنوك الأسئلة، حالة توفر الألعاب |
| `js/games.js` | محركات الألعاب الستة |
| `js/app.js` | الشاشات، التنقّل، النقاط، الشارات، المتصدرون، الصوت |
| `manifest.json` + `sw.js` | التثبيت كتطبيق (PWA) والعمل بدون إنترنت |
| `validate.node.js` | فاحص بنك الأسئلة من سطر الأوامر |

## الألعاب الستة

| اللعبة | النوع | عدد الجولات |
|--------|-------|-------------|
| ⚡ اختبار سريع | اختيار من متعدد + شرح | 10 أسئلة |
| ⏱️ سباق الوقت | اختيار من متعدد مع أرواح | 60 ثانية |
| ✅ صح أم خطأ | حكم على عبارات | 12 عبارة |
| ⌨️ اكتب الإجابة | إدخال رقمي بلوحة مفاتيح على الشاشة | 10 أسئلة |
| 🧩 المطابقة | طابق الطرف بمقابله | 3 جولات × 4 أزواج |
| 🎚️ ترتيب الأرقام | تصاعدي/تنازلي بالنقر | 4 جولات |

تُفعَّل اللعبة تلقائياً لكل وحدة يملك بنك الأسئلة نوعاً كافياً من الأسئلة (يظهر تنبيه إن لم تتوفر).

## إضافة أسئلة

كل سؤال يُبنى بإحدى الدوال الخمس في `helpers.js`:

```js
mc({ q: 'ما ناتج 3 × 4؟', a: '12', o: ['10', '14', '16'], e: 'الضرب تكرار للجمع.', k: 'المهارة' })
tf({ q: 'مجموع زوايا المثلث 180°.', a: true, e: 'قانون ثابت.', k: 'المثلثات' })
num({ q: '2x + 5 = 11 إذن x = ؟', a: 3, e: 'اطرح 5 ثم اقسم على 2.', k: 'المعادلات' })
pairs({ p: [['المتوسط', 'المجموع ÷ العدد'], ['الوسيط', 'القيمة الوسطى']], e: '', k: 'الإحصاء' })
order({ v: [0.5, 1/4, 2, 3], dir: 'asc', q: 'رتب تصاعدياً', e: '', k: 'الترتيب' })
```

ثم تحقّق من سلامة البنك:

```bash
node validate.node.js            # كل الملفات
node validate.node.js js/data/g1.js
```

يعرض الفاحص جدداً بعدد الأسئلة لكل وحدة ونوع، ويكتشف الأخطاء (فهرس خاطئ، خيارات مكررة، إجابة
غير رقمية، أزواج مكررة، أسئلة مكررة…) وينتهي برمز `1` عند وجود أخطاء.

## ملاحظات

- كل التقدّم (النقاط، الشارات، الإحصاءات، المتصدرون) يُحفظ في `localStorage` داخل الجهاز — لا خوادم ولا حسابات.
- الأرقام في الأسئلة بصيغة غربية (123) لتوحيد الإدخال مع لوحة المفاتيح.

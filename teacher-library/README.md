# مكتبتي التعليمية للمعلمة الليبية

مشروع ويب عربي (RTL) لتصميم **ملفات وسجلات المعلمة** بمقاس **A4**، بألوان
البيج والوردي الغباري والبني الهادئ، مع زخارف زهور خفيفة، قابلة للتعديل والطباعة
أو التصدير إلى **PDF** بجودة متجهة.

> **تنويه مهم:** جميع النماذج **تجريبية** أُعدّت لتنظيم العمل اليومي وتطويره
> شخصيًا، وهي **ليست نماذج معتمدة رسميًا** في ليبيا ولا تُغني عن أي استمارة رسمية
> صادرة عن الإدارة التعليمية. البيانات المعروضة تجريبية وقابلة للتعديل بالكامل.

---

## 1) التشغيل

### الطريقة الأولى — الخادم المحلي (موصى بها)
```bash
cd teacher-library
node server.js
```
ثم افتحي المتصفح على: **http://localhost:4173**

أو باستخدام npm:
```bash
npm start
```

### الطريقة الثانية — فتح الملف مباشرة
انقرِي مرتين على `index.html` (يعمل أيضًا، لكن الطباعة عبر HTTP أدق).

**المتطلبات:** متصفح حديث (Chrome / Edge / Firefox) و Node.js 16+ للخادم فقط.
لا توجد أي اعتماديات خارجية تحتاج تثبيتًا.

## 2) واجهة الاستخدام

| المنطقة | الوظيفة |
|---|---|
| **البطاقات الرئيسية** | 10 ملفات، لكل بطاقة زرّان: «فتح الملف» و«طباعة / PDF» |
| **شريط البحث** | يفلتر الملفات بالاسم أو الوصف أو الوسوم |
| **الإعدادات والبيانات** | اسم المعلمة، المدرسة، السنة الدراسية، المادة، الصف، الإدارة التعليمية، مدير المدرسة، الرقم الوظيفي |
| **عارض الصفحات** | فهرس جانبي، تنقّل (السابق/التالي)، تكبير/تصغير، مؤشر رقم الصفحة |
| **التحرير** | انقرِي على أي حقل أو خلية أو عنوان وعدّليه مباشرة |

### الملفات العشرة (63 صفحة A4)
1. ملف الأداء الوظيفي — 8 صفحات
2. ملف الإنجاز المهني — 7 صفحات

4. سجل متابعة الطالبات — 6 صفحات
5. سجل التحصيل الدراسي — 6 صفحات
6. ملف الخطط الفصلية والسنوية — 6 صفحات
7. سجل تحليل نتائج الاختبارات — 6 صفحات

كل ملف يتكوّن من: **غلاف + فهرس (يتحدث تلقائيًا) + فاصل + صفحات داخلية**.

## 3) التصدير إلى PDF بمقاس A4

1. افتحِي الملف المطلوب من الواجهة الرئيسية.
2. اضغطي زر **«تصدير PDF / طباعة»** (أو **«طباعة الصفحة»** للصفحة الحالية فقط).
3. في نافذة الطباعة اختاري:
   - **الوجهة:** حفظ كـ PDF
   - **الورق:** A4
   - **الهوامش:** بلا *(مهم جدًا)*
   - **رسومات الخلفية (Background graphics):** فعّّليها *(لتظهر الألوان والزخارف)*
4. اسم ملف الافتراضي سيحمل اسم الملف واسم المعلمة تلقائيًا.

> **اختصارات لوحة المفاتيح:** `→` / `←` للتنقل بين الصفحات، `Esc` للعودة للرئيسية.

### تحقّق مِن النتائج
صُدّرت الملفات العشرة فعليًا واختُبرت: **كلها بمقاس A4 دقيق (595×842 نقطة)**
مع خطوط عربية مضمّنة وعدد صفحات مطابق. شاهدِي العينات في مجلد
[`samples/`](samples/) — منها `grades.pdf` و`certificates.pdf` و`prep.pdf`.

## 4) حفظ التعديلات

- كل تعديل يُحفظ **تلقائيًا** في متصفحك (`localStorage`) خلال نصف ثانية.
- شريط الحالة أسفل الصفحة يعرض: «تم الحفظ ✓» أو «تم استرجاع N حقلًا».
- من **الإعدادات** يمكنكِ:
  - **تصدير بيانات JSON** — نسخة احتياطية تحفظينها على جهازك.
  - **استيراد ملف JSON** — لاستعادة بياناتك على جهاز أو متصفح آخر.
  - **مسح كل التعديلات** — للعودة إلى النماذج الأصلية.

> الحفظ محلي في المتصفح فقط. للحفاظ الدائم على عملك نزّلي نسخة JSON بين الحين والآخر.

## 5) بنية المشروع

```
teacher-library/
├── index.html        الواجهة الرئيسية + العارض + النوافذ
├── css/app.css       التنسيق العام + صفحات A4 + الزخارف
├── css/print.css     قواعد الطباعة A4 وكسر الصفحات
├── js/data.js        الإعدادات الافتراضية + تعريف الملفات العشرة
├── js/pages.js       مولّد الصفحات (غلاف/فهرس/فاصل/جدول/شهادة)
├── js/store.js       الحفظ المحلي + تصدير/استيراد JSON
├── js/app.js         التنقّل، التحرير، التكبير، الطباعة
├── server.js         خادم محلي بدون اعتماديات
├── tests/smoke.js    1597 فحصًا برمجيًا لبنية الصفحات
└── samples/          عينات PDF مُصدَّرة فعليًا
```

### إضافة محتوى جديد
افتحي `js/data.js` وأضيفي صفًا إلى جدول، أو صفحة جديدة إلى `pages` بالأنواع
المتاحة: `cover`، `index`، `divider`، `table`، `form`، `text`، `certificate`.

مثال لإضافة صف إلى جدول:
```js
[ FIX('1'), 'اسم الطالبة', '95', 'مميّز', 'ملاحظة' ],
```
- نص عادي → خلية **قابلة للتعديل**.
- `FIX('…')` → خلية **ثابتة** (كأرقام الصفوف).
- `BIND('teacher')` → خلية **مرتبطة** بالإعدادات العامة.
- عمود `م` الأول يُرقَّم **تلقائيًا**.

## 7) حلّ المشاكل

| المشكلة | الحل |
|---|---|
| الطباعة تُظهر صفحة بيضاء | افتحي الصفحة عبر `http://localhost:4173` وليس بالنقر المزدوج |
| الألوان لا تظهر في PDF | فعّلي «رسومات الخلفية» في نافذة الطباعة |
| ظهرت هامش بيضاء حول الصفحة | اضبطي الهوامش على «بلا / None» |
| التعديلات لم تُحفظ | تأكّدي أن المتصفح لا يعمل في وضع التصفح الخاص |
| الخط العربي غير جميل | انتظري تحميل الخطوط من الإنترنت، أو استمرّي بخط النظام |

# خطة تنفيذ مشروع «مكتبتي التعليمية للمعلمة الليبية»

## 1. الهدف
مشروع ويب يعمل فعليًا (ليس صورة أو نموذج شكليًا) يعرض 10 ملفات تعليمية عربية بتصميم
بيج/وردي غباري/بني هادئ، اتجاه RTL، مقاس A4، قابلة للتعديل والطباعة/التصدير إلى PDF.

> تنويه: النماذج تجريبية لأغراض التنظيم والتخطيط الشخصي، **وليست نماذج معتمدة رسميًا** في ليبيا.

## 2. المنهجية
- تقنية: HTML + CSS + JavaScript خالص (بدون إطار عمل)، ليعمل المشروع فورًا بلا اعتماديات ثقيلة.
- خادم محلي مدمج بـ Node.js بدون تبعيات (`server.js`) لتجربة الطباعة عبر HTTP (أدق من file://).
- التصدير إلى PDF عبر محرك الطباعة في المتصفح مع ورقة `@page { size: A4; margin: 0 }`
  (يحافظ على النص العربي المتصل والاتجاه RTL بجودة متجهة، خيار «رسومات الخلفية» للألوان).
- الحفظ المحلي عبر `localStorage` مع تصدير/استيراد نسخة احتياطية JSON.

## 3. بنية المشروع
```
teacher-library/
├── PLAN.md              هذه الخطة
├── README.md            طريقة التشغيل والاستخدام والتصدير
├── package.json         سكربتات start/test
├── server.js            خادم ثابت بدون اعتماديات
├── index.html           الواجهة الرئيسية (بطاقات الملفات + العارض + الإعدادات)
├── css/
│   ├── app.css          واجهة التطبيق + تنسيق الصفحات A4 + الزخارف
│   └── print.css        قواعد الطباعة/PDF والصفحات
├── js/
│   ├── data.js          الإعدادات الافتراضية + تعريف الملفات العشرة ومواصفات صفحاتها
│   ├── pages.js         مولّد الصفحات (غلاف، فهرس، فاصل، جداول، بطاقات، شهادات)
│   ├── store.js         الحفظ المحلي، الاسترجاع، تصدير/استيراد JSON
│   └── app.js           التنقل، العرض، التحرير، التكبير، الطباعة
└── tests/
    └── smoke.js         فحص برمجي سريع (بنية الصفحات، المفاتيح، التخزين)
```

## 4. الملفات العشرة (كل ملف: غلاف + فهرس + فواصل + صفحات داخلية)
1. ملف الأداء الوظيفي — بيانات شخصية، المهام، تقييم ذاتي، مؤشرات أداء، خطة تطوير.
2. ملف الإنجاز المهني — إنجازات، دورات تدريبية، شهادات، ملخص وأهداف.
3. ملف التحضير اليومي — بطاقة تحضير ×2، جدول تحضير أسبوعي.
4. سجل متابعة الطالبات — حضور ومشاركة، متابعة سلوك وتحفيز، خطة متابعة فردية.
5. سجل التحصيل الدراسي — الدرجات، تحصيل المهارات، تحليل النتائج.
6. ملف الخطط الفصلية والسنوية — خطة سنوية، خطة فصلية، أهداف وموارد.
7. سجل تحليل نتائج الاختبارات — نتائج، تحليل فقرات، مؤشرات وتوصيات.
8. سجل الأنشطة والمبادرات — الأنشطة، بطاقة مبادرة، فريق العمل.
9. سجل الاجتماعات والتقارير — محاضر اجتماعات، تقرير نشاط، سجل التقارير.
10. شهادات الشكر والتقدير — نموذجا شهادة + سجل الشهادات.

عدد الصفحات المتوقع: ~55 صفحة A4.

## 5. المزايا البرمجية
- واجهة رئيسية: بحث/فلترة + بطاقات أنيقة لكل ملف + زر معاينة وطباعة سريع.
- فتح كل ملف: عارض صفحات مع تنقّل (السابق/التالي)، أرقام صفحات عربية، فهرس جانبي.
- تحرير: كل حقل/خلية قابلة للنقر والتعديل (`contenteditable`) مع مفاتيح ثابتة للحفظ.
- إعدادات عامة: اسم المعلمة، المدرسة، السنة الدراسية، المادة، الصف، الإدارة التعليمية
  تُطبَّق تلقائيًا على الأغلفة والفهارس والفواصل وتذييلات الصفحات عبر `data-bind`.
- حفظ محلي تلقائي (localStorage) + مؤشر «تم الحفظ» + تصدير/استيراد JSON + استعادة النموذج.
- الطباعة: الملف كاملًا أو الصفحة الحالية، مقاس A4 بلا هوامش، خلفيات مطبوعة.
- تجاوب كامل: هاتف/لوحي/كمبيوتر (شبكة بطاقات مرنة + تكبير تلقائي للصفحات).

## 6. خطوات التنفيذ
1. إنشاء الهيكل وملف الخطة (هذا الملف).
2. كتابة `index.html` و`css/app.css` (واجهة + بطاقات + عارض).
3. كتابة `js/data.js` (10 ملفات ومواصفات صفحاتها) و`js/pages.js` (مولّد الصفحات).
4. كتابة `js/store.js` و`js/app.js` (حفظ، تحرير، تنقل، طباعة).
5. كتابة `css/print.css` (A4، كسر الصفحات، إخفاء عناصر الواجهة).
6. `server.js` + `package.json` + `README.md`.
7. التشغيل والاختبار: فحص برمجي (tests/smoke.js)، اختبار متصفح (فتح الواجهة، فتح ملف،
   تعديل حقل وإعادة تحميل للتأكد من الحفظ، فحص وحدة التحكم)، ثم إصلاح الأخطاء.

## 7. معايير القبول
- لا أخطاء في وحدة التحكم، وكل الملفات العشرة تفتح وتعرض صفحاتها.
- تعديل حقل يبقى بعد إعادة تحميل الصفحة.
- أرقام الصفحات والفهرس صحيحة، التصميم ألوانه بيج/وردي/بني والاتجاه RTL.
- الطباعة تعرض صفحات A4 كاملة بدون قصّ أو تداخل.
